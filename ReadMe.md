# Overview

A basic 2048 app that had modular settings for a customized experience. The main screen is 2048 on a 4x4 grid and generating 2 and 4 blocks like a normal game. It has interactive controls for slidingas well as buttons. The settings page lets you have more control over the game, like the board size and what blocks can spawn up to 16.


# Development Environment

Expo Go was used to test the application

I used React native Javascript to create the website as I recognize both of them from my web development experience and wanted to try them out.
